# Trinh Xuan Dat — Portfolio

Personal portfolio featuring full-stack development, AI automation, and multi-agent systems projects.

## Contents

- `index.html`: responsive, single-page portfolio with English and Vietnamese language options.
- `assets/`: project images, research poster, and charts.
- `Portfolio_Trinh_Xuan_Dat_EN.pdf`: English PDF portfolio.
- `Portfolio_Trinh_Xuan_Dat_VI.pdf`: Vietnamese PDF portfolio.

## Preview

Open `index.html` in a browser. Use the EN/VI buttons to switch languages, or add `?lang=vi` to the website URL.

## Deploy to Vercel

Import this GitHub repository into Vercel with these settings:

- Framework Preset: **Other**.
- Root Directory: repository root (`./`).
- Build Command: enable Override and leave the command empty.
- Output Directory: `.`.
- Environment Variables: none required.

The site uses plain HTML, CSS, and JavaScript and requires no dependency installation or build step.
